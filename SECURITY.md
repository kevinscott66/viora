# Security

Report suspected vulnerabilities privately to hello@dobropalm.tech. Do not include keys, tokens, recovery codes, user messages or personal media in a public issue.

Review covers local file boundaries, HTTP API ownership, public-link validation and chat/recovery behavior. Public links intentionally disclose their selected payload. Physical-device storage protections, dependency implementations and deployed infrastructure require their own verification. No independent cryptographic certification is claimed.

Never commit credentials, device backups, databases, signed packages, real music/catalog/lyrics/covers or operational logs. Use fictional fixtures. Keep the API disabled until an operator configures a separate service. Trusted proxy headers must be explicitly enabled only behind a proxy that overwrites them.
